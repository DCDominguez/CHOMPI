1say it

What should it sound like?

2let a chatbot forge it

  1. Paste the prompt into any chatbot: ChatGPT, Claude, Gemini, whatever's open.
  2. Copy its whole reply and drop it here.

Forge checks the reply before it touches the editor. Nothing is sent anywhere by Forge.

What Choowi can build: two oscillators and noise, a sampler for the WAV files on CHOMPI's card (TAPE layout) and its recording, up to seven voices, envelopes, a resonant filter, an LFO, glide, delay, reverb, chords and an arp. A chatbot can only pick settings for these; it can't make audio, so a sampler sound plays a file that's already on the card.
